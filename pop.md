## Project Goal (Gabriella)
{ Provide a broad, high-level statement that articulates the desired outcome of the project. For example: “provide excellent customer service”} 

The goal of the Media Collection Tracker is to develop a secure and user-friendly web application that allows users to organize, manage, and track their personal media collections. The application will provide one centralized location for managing movies, TV shows, books, music, and video games. 

## Project Objectives (Alexandra) 
{List at least 3 specific, measurable, achievable, relevant, and time-bound (SMART) target that a project aims to achieve. It outlines the tangible outcomes or results that the project intends to deliver. For example: “reduce customer wait time to one minute” } 

Develop a functional web application using Python and Django. 
Allow users to securely register, log in, and manage their personal media collections. 
Allow users to add, edit, delete, categorize, and rate media items. 
Provide search, filtering, and status-tracking features for users to easily manage their collections. 
Complete testing and debugging to ensure the application is ready for final submission 

## Project Scope (Jemimah) 
{Specify the boundaries and extent of the project, outlining what is included and what is excluded. Provides a clear understanding of the project's focus.} 

The project will focus on developing a web application for man aging personal media collections. It will include user registration and login, adding and managing media items, categorizing and rating media, searching and filtering collections, and tracking media status. 

The project will focus on collection management and will not include features such as media streaming, purchasing or selling media, social networking, or public collection sharing.

## Project Management Plan and Methodologies (Gabriella) 
{Specify what project management methods and tools will be used in this project development. Describe how your group will use these project management methods and tools during this project development.} 
 
The team will use the Agile Scrum methodology to manage the project. Development will be divided into five springs, with tasks assigned during sprint planning. The team will use sprint planning to assign tasks, regular meetings to discuss progress and issues, and sprint reviews and retrospectives to evaluate the team’s progress. GitHub will be used to track development tasks and code changes, while Microsoft Teams will be used for team communication.
